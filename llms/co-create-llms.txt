# Co:Create

> Co:Create (Gesso Labs, Inc.) was an a16z crypto-backed web3 platform providing an API-first toolkit for token-driven loyalty, rewards, and community programs on the Polygon blockchain. Brands used its REST API to manage users and hosted wallets; deploy and manage ERC-20, ERC-721, ERC-1155, and Soulbound token contracts; mint and transfer tokens (synchronous and asynchronous with status polling); and run Campaigns, Referrals, Redemptions, Auctions, and Prize Draws, plus NFT media/metadata hosting and fiat/crypto checkout. The public developer surface (docs.usecocreate.io, api.cocrt.xyz) is now offline; this profile is reconstructed from the provider's own published documentation via the Internet Archive.

## APIs

- [Co:Create API reference](https://docs.usecocreate.io/reference): REST API for users/wallets, ERC-20/721/1155 and Soulbound tokens, Campaigns, Referrals, Redemptions, Auctions, Prize Draws, and NFT media/metadata. Production base URL: https://api.cocrt.xyz — Sandbox: https://api.testcocrt.xyz
